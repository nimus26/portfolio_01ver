카드 상품과 이벤트 정보가 한 화면에서 섞여 보이는 문제를 중심으로, 사용자가 필요한 혜택과 상품 정보를 빠르게 비교할 수 있도록 정보 흐름을 재정리한 리뉴얼 프로젝트입니다.

Design Review

웹의 3D 전환을 펼친 버전입니다. 디자인 수정용으로 모든 섹션을 한 화면 흐름에 배치했습니다.

01 / 화면 근거

문제

기존 화면은 배너, 메뉴, 카드 상품 분류가 한꺼번에 노출되어 사용자가 어떤 정보부터 확인해야 하는지 판단하기 어려웠습니다.

목표

메인 화면의 정보 우선순위를 명확히 하고, 로그인 전후 맥락과 카드 상품 탐색 흐름을 분리하는 것이 목표였습니다.

나의 역할

문제 정의, 정보 구조 정리, 화면 설계, 리디자인 방향 설정, HTML/CSS 기반 구현까지 개인 작업으로 진행했습니다.

03 / 해결안 · 주요 화면

메인 비주얼은 서비스 인상을 만드는 영역으로 두고, 이벤트와 카드 상품 정보는 별도 흐름으로 분리했습니다. 카드 선택 영역은 목적 중심 카테고리로 묶어 비교 부담을 줄였습니다.

04 / 상황 · 행동 · 결과

01

상황: 카드 상품, 이벤트, 메뉴 정보가 동시에 노출되어 핵심 혜택 파악이 어려웠습니다.

02

행동: 메인 비주얼, 이벤트 안내, 카드 탐색 영역을 역할별로 나누었습니다.

03

결과: 정보 접근성과 시각적 위계 개선에 대한 긍정 피드백을 확인했습니다.

05 / 배운 점

정보가 많은 서비스일수록 사용자가 먼저 확인해야 할 판단 기준을 분명히 만드는 것이 중요하다는 점을 배웠습니다.
